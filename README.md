# Semarang Weather ETL

An ETL pipeline that retrieves hourly weather forecasts for Semarang from the Open-Meteo API, transforms and cleans the data, and loads it into a SQLite database.

## Pipeline Overview

Open-Meteo API → Extract → Transform → Load → SQLite (`hourly_weather`)

## Design Decisions

* **Time handling:** Timestamps are stored as local Western Indonesian Time (WIB, UTC+7), represented as text without timezone information.
* **Idempotency:** The `date` column serves as a unique key. Upserts ensure that the latest values replace existing records with the same timestamp.
* **Data characteristics:** The pipeline processes model-based weather forecasts. Forecast values for a given hour may change between runs as new forecasts become available.
* **Units:** Column names include their measurement units where applicable, such as `temperature_c` and `rain_mm`.
* **Database:** SQLite is used for simplicity and ease of development. Separating database operations into `load.py` makes it easier to migrate to PostgreSQL in the future.

## Database Schema

| Column                   | Data Type          | Unit |
| ------------------------ | ------------------ | ---- |
| `date`                   | TEXT (Primary Key) | WIB  |
| `temperature_c`          | REAL               | °C   |
| `rain_mm`                | REAL               | mm   |
| `humidity_pct`           | REAL               | %    |
| `precip_probability_pct` | REAL               | %    |
| `wind_speed_kmh`         | REAL               | km/h |

## Example Query

Calculate the average hourly temperature for each day:

```sql
SELECT
    DATE(date) AS day,
    AVG(temperature_c) AS average_temperature_c
FROM hourly_weather
GROUP BY DATE(date)
ORDER BY day;
```
